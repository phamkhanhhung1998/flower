# Bó hoa tặng nàng 🌷

Trang quà tặng 20/10: chạm bé thỏ → bó tulip nở → mở phong thư đọc lời nhắn, có ảnh kỷ niệm bay lượn.

- **Tạo quà:** mở `create.html`, nhập nội dung, chọn ảnh, bấm **Tạo Link** rồi gửi link cho người nhận.
- Toàn bộ nội dung (kể cả ảnh đã thu nhỏ) nằm trong phần `#d=...` của link, không lưu trên server.
- Trang tĩnh, chạy được trên GitHub Pages.
